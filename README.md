# Zomato-powerbi-analysis
End-to-end Zomato order and restaurant analysis using MySQL for data cleaning and transformation, and Power BI with DAX for interactive dashboards.
Zomato Order & Restaurant Analysis (SQL + Power BI)

Tools: MySQL, Power BI, DAX, CSV

Objectives:

Analyze restaurant performance by orders and ratings
Identify top-performing cities and restaurants
Study how pricing affects customer orders
Evaluate delivery efficiency
Build interactive dashboards for business decisions

SQL work:

Checked the data for NULL values (none found)
Counted restaurants per city
Ranked cities by order volume (Mumbai highest with 127 orders)
Calculated revenue per restaurant and the top 5 restaurants by sales
Computed average order value per city (Bangalore highest at about 1090)
